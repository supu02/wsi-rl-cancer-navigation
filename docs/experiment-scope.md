# Experiment Scope and Reproduction Notes

## PPO Navigation Prototype

The `RLogist/` code expects three files per slide in `embeddings/`:

- `<slide>.npy`: an `(N, 384)` matrix of patch embeddings
- `<slide>_coords.npy`: an `(N, 2)` coordinate matrix
- `<slide>_mask.npy`: a tumor mask aligned with the patches

The included `train_camelyon.py` is a small prototype. It samples from two hard-coded slide IDs for 200 episodes; it is not the full report evaluation protocol. The evaluator uses a fixed list of ten slide IDs and skips any whose embedding file is absent. Treat reported metrics as comparable only when the same slide split, data preprocessing, checkpoint, and episode protocol are used.

Example:

```bash
python -m RLogist.train_camelyon --reward dense
python -m RLogist.rl.evaluate_camelyon --reward dense --episodes-per-slide 20 --max-steps 100
```

Evaluation checkpoints are expected under `RLogist/checkpoints/`. Evaluation metrics and episode logs are written to `results/`; both locations are ignored by Git.

## UNI2-h Feature Extraction

`sasha_adapted/preprocessing/step2_extract_uni2_features.py` extracts raw 1,536-dimensional UNI2-h features. It expects external CAMELYON16 slides, SASHA patch HDF5 files containing `coords`, a slide CSV, and Hugging Face access to `MahmoodLab/UNI2-h`.

Example command (replace the paths with local data locations):

```bash
python sasha_adapted/preprocessing/step2_extract_uni2_features.py \
  --dataset_name camelyon16 \
  --data_h5_dir /path/to/SASHA/patches_subset16 \
  --data_slide_dir /path/to/CAMELYON16/slides \
  --slide_ext .tif \
  --csv_path /path/to/camelyon16_subset16.csv \
  --feat_dir outputs/features_uni2_subset16 \
  --batch_size 4 \
  --extract_high_res_features True \
  --patch_level_low_res 3 \
  --patch_level_high_res 1 \
  --smoke_test --max_slides 1 --max_patches_per_slide 8
```

The extraction code is not wired into the 384-dimensional PPO prototype. The matching downstream SASHA training stages and their trained classifier/global-update checkpoints are external and are not included here; no end-to-end UNI2 PPO result is claimed by this repository.

## Data Handling

Do not commit raw whole-slide images, patient-level data, extracted embeddings, model weights, or run outputs. Keep them in ignored local directories or approved storage and verify the CAMELYON16 and model license/access terms before use.
