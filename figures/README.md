# Figures

This folder retains the repository's previously published architecture, preprocessing, and training figures and adds `reward_shaping_comparison.png` from the report workspace.

The newly added comparison image is a reference figure; its raw source metrics were not available to regenerate it. Other existing plots predate the currently included source subset and have not been revalidated against it. Do not treat these images alone as a reproducible evaluation; see `docs/experiment-scope.md` for limitations.
